# G2 Remote OS (iOS)

**Even Realities G2** 순정 펌웨어를 유지한 채, 아이폰 **화면 꺼짐(백그라운드)** 상태에서도 **Flic Duo** 리모콘(또는 배송 전 앱 내 가상 패드)으로 G2의 모든 조작(상·하·좌·우, 스크롤, 선택/뒤로/홈, **G2 내장 마이크 On/Off 및 LC3 음성 스트림 수신**, 밝기·무음·절전)을 수행하는 네이티브 Swift iOS 앱입니다.

---

## 주요 기능 (v0.1 — 전체 조작 검증용 미니 OS)

| G2 화면 앱 | 조작 및 기능 |
| :--- | :--- |
| **1. 홈 런처 (2×3 그리드)** | 상·하·좌·우 4방향 이동, 확인 진입, 전역 마이크 토글 |
| **2. 대시보드** | 시계, G2/Flic 배터리, 리모콘 단축키 가이드, 최근 입력 이력 (좌/우 3페이지) |
| **3. 스크롤 리더 / 텔레프롬프터** | 위/아래·Twist 정밀 줄 스크롤, 좌/우 문서 전환, 확인으로 자동 스크롤, 앱에서 사용자 메모 직접 전송 |
| **4. G2 마이크 컨트롤** | G2 내장 마이크(`0x6402` raw LC3 16kHz) 원격 On/Off, 실시간 패킷/시간/신호레벨/방향(DOA) 표시, `.lc3` 녹음 파일 저장 |
| **5. 4방향 & 스크롤 패드** | `5×11` 격자 커서로 상·하·좌·우 및 스크롤 감도를 G2 화면에서 즉시 검증 |
| **6. 기기 설정** | 좌/우로 G2 밝기(`1~50`) 실시간 조절, 무음 모드 On/Off, 배터리/펌웨어 조회, 화면 절전/즉시 깨우기 |

## Flic Duo 기본 조작 매핑 (화면 꺼짐 백그라운드 지원)

* **큰 버튼 (Button 0)**
  * 클릭: **확인 / 선택**
  * 더블클릭: **뒤로가기**
  * 길게 누르기(Hold): **G2 내장 마이크 On/Off** *(Flic Duo 내장 버저로 켜짐/꺼짐 피드백)*
  * 누르고 비틀기(Push & Twist): **연속 스크롤 업 / 다운**
  * 누르고 상·하·좌·우 스와이프: **상 / 하 / 좌 / 우 방향 이동**
* **작은 버튼 (Button 1)**
  * 클릭: **아래로 / 스크롤 다운**
  * 더블클릭: **위로 / 스크롤 업**
  * 길게 누르기(Hold): **홈 런처 복귀** *(이미 홈 화면이면 G2 화면 절전/깨우기)*
  * 누르고 비틀기(Push & Twist): **G2 밝기 +/-**

> Flic Duo가 도착하기 전에도 앱의 **리모콘 탭 → 전체 조작 패드 / 가상 Flic Duo**로 모든 기능을 G2 실기에서 바로 테스트할 수 있습니다.

## Mac 없이 무료로 `.ipa` 빌드 & 아이폰 설치 가이드 (SideStore)

### 1단계: 원클릭으로 GitHub Actions 무료 `.ipa` 빌드 받기
Windows PowerShell에서 아래 한 줄을 실행하면 **GitHub 로그인 → 저장소 생성 → 코드 푸시 → macOS 무료 빌드 & 테스트 → `build\G2RemoteOS.ipa` 자동 다운로드**까지 한 번에 완료됩니다.

```powershell
# (추천: Public 저장소는 GitHub Actions macOS 빌드 시간이 무제한 무료)
.\scripts\publish_and_build.ps1 -Public

# (비공개 저장소로 빌드하려면 -Public 생략)
.\scripts\publish_and_build.ps1
```

*(직접 수동으로 올리시려면 GitHub에 새 저장소를 만들고 `c:\G2`를 push한 뒤 **Actions → Build iOS IPA (SideStore) → Artifacts → `G2RemoteOS-ipa`** 에서 다운로드하세요.)*

### 2단계: Windows PC에서 최초 1회 SideStore 설치
1. [SideStore 공식 가이드](https://docs.sidestore.io/)에 따라 Windows PC에 **AltServer** 와 **iTunes / iCloud (Apple 공식 설치판)** 를 설치하고, 아이폰을 USB로 연결해 **SideStore** 및 페어링 파일을 최초 1회 설치합니다.
2. 아이폰에서 **StosVPN** (SideStore 안내 앱) 프로필을 활성화합니다.
3. 아이폰 **파일** 앱에 받은 `G2RemoteOS.ipa`를 **SideStore → My Apps → `+`** 로 설치합니다.

### 3단계: 7일 만료 무료 자동 갱신 설정 (PC 불필요)
1. 아이폰 기본 **단축어(Shortcuts)** 앱 → **자동화** 탭 → `+` → **특정 시간** 선택 *(예: 매주 월·목 새벽 3시, "즉시 실행")*
2. 동작 추가:
   1. **VPN 설정** → `StosVPN` **연결**
   2. **대기** → `10초`
   3. **SideStore → Refresh All Apps**
   4. **VPN 설정** → `StosVPN` **연결 해제**
3. 이후에는 PC를 연결할 필요 없이 Wi-Fi 환경에서 7일 서명이 자동으로 갱신됩니다.

## 실기 연결 순서 (중요!)

1. **공식 Even Realities 앱을 완전히 종료**하세요. *(G2 안경은 한 번에 하나의 호스트만 BLE 연결을 허용하며, 연결 중에는 Advertising을 중단합니다.)*
2. **G2 Remote OS** 앱 → **기기 연결** 탭 → **G2 안경 스캔** → `G2 Pair`가 좌/우(`L`/`R`) 모두 뜨면 **연결** 버튼 클릭.
3. 연결 직후 G2 안경에 홈 런처 화면이 표시됩니다.
4. *(Flic Duo 도착 후)* 같은 화면 하단에서 **Flic Duo 페어링 스캔**을 누르고, Flic Duo 버튼을 6초 이상 길게 눌러 페어링합니다.
5. **설정/로그** 탭에서 **화면 꺼짐 백그라운드 상시 유지** 옵션을 켜두면 아이폰 화면을 꺼도 4초 G2 하트비트가 끊기지 않고 유지됩니다.
